# ML Playbook: Roadmap

**Цель:** подготовиться к стажировке ML-инженера / Data Scientist.
**Формат:** каждая глава пишется по шаблону `templates/chapter.md`. Когда глава готова, в её шапке `status: done`, а здесь ставится галочка.

## Этапы

### 1. Математика → [01-math](01-math/)
- [ ] Линейная алгебра: векторы, матрицы, собственные значения, SVD
- [ ] Матанализ: производные, градиент, цепное правило
- [ ] Теория вероятностей: распределения, условная вероятность, Байес
- [ ] Статистика: оценки, доверительные интервалы, проверка гипотез

### 2. Python и инструменты → [02-python-tools](02-python-tools/)
- [ ] NumPy
- [ ] Pandas
- [ ] Matplotlib / Seaborn
- [ ] scikit-learn: пайплайны, кросс-валидация

### 3. Классический ML → [03-classical-ml](03-classical-ml/)
- [ ] Линейная и логистическая регрессия
- [ ] Метрики качества (accuracy, precision/recall, ROC-AUC, MSE и др.)
- [ ] Переобучение, регуляризация, bias-variance
- [ ] Деревья, случайный лес
- [ ] Градиентный бустинг
- [ ] Кластеризация, понижение размерности (PCA)
- [ ] Feature engineering

### 4. Глубокое обучение → [04-deep-learning](04-deep-learning/)
- [ ] Перцептрон, backpropagation
- [ ] Оптимизаторы (SGD, Adam)
- [ ] Регуляризация в нейросетях (dropout, batch norm)
- [ ] PyTorch
- [ ] CNN
- [ ] RNN / LSTM
- [ ] Attention и Transformer

### 5. NLP и CV → [05-nlp-cv](05-nlp-cv/)
- [ ] Эмбеддинги, токенизация
- [ ] Классификация текста
- [ ] Работа с изображениями, transfer learning

### 6. MLOps (основы) → [06-mlops-basics](06-mlops-basics/)
- [ ] Git, окружения, воспроизводимость
- [ ] Эксперименты и трекинг (MLflow или аналог)
- [ ] Деплой модели: FastAPI, Docker

### 7. Подготовка к собеседованиям → [07-interview](07-interview/)
- [ ] Теоретические вопросы по ML
- [ ] Задачи по Python и SQL
- [ ] Алгоритмы и структуры данных (базовый уровень)
- [ ] Разбор ML-кейсов

## Практика

- [ ] Первый проект: end-to-end на табличных данных
- [ ] Второй проект: нейросети (NLP или CV)
- [ ] Участие в соревновании на Kaggle
- [ ] Оформить репозитории и резюме
