# ML Playbook: Roadmap

**Цель:** подготовиться к стажировке ML-инженера / Data Scientist, а также к вакансиям уровня «стажёр Python / AI-разработчик» (backend + LLM, RAG, агенты).
**Формат:** каждая глава пишется по шаблону `templates/chapter.md`. Когда глава готова, в её шапке `status: done`, а здесь ставится галочка.

**Порядок:** номер папки соответствует рекомендуемой очерёдности изучения.

## Этапы

### 1. Python и инструменты → [01-python-tools](01-python-tools/)
- [ ] Python: ООП, структуры данных, итераторы и генераторы, декораторы, типизация
- [ ] Асинхронное программирование: asyncio, async/await
- [ ] Тестирование и качество кода: pytest, код-ревью
- [ ] SQL: SELECT, JOIN, GROUP BY, оконные функции, индексы
- [ ] NumPy
- [ ] Pandas
- [ ] Matplotlib / Seaborn
- [ ] scikit-learn: пайплайны, кросс-валидация

### 2. Backend и MLOps (основы) → [02-mlops-basics](02-mlops-basics/)
- [ ] Git, окружения, воспроизводимость
- [ ] REST API и клиент-серверная архитектура: HTTP, методы, статусы, JSON
- [ ] FastAPI: маршруты, Pydantic, асинхронные эндпоинты
- [ ] Работа с БД из Python, интеграция с внешними API
- [ ] Эксперименты и трекинг (MLflow или аналог)
- [ ] Деплой модели: Docker

### 3. Математика → [03-math](03-math/)
- [ ] Линейная алгебра: векторы, матрицы, собственные значения, SVD
- [ ] Матанализ: производные, градиент, цепное правило
- [ ] Теория вероятностей: распределения, условная вероятность, Байес
- [ ] Статистика: оценки, доверительные интервалы, проверка гипотез

### 4. Классический ML → [04-classical-ml](04-classical-ml/)
- [ ] Линейная и логистическая регрессия
- [ ] Метрики качества (accuracy, precision/recall, ROC-AUC, MSE и др.)
- [ ] Переобучение, регуляризация, bias-variance
- [ ] Деревья, случайный лес
- [ ] Градиентный бустинг
- [ ] Кластеризация, понижение размерности (PCA)
- [ ] Feature engineering

### 5. Глубокое обучение → [05-deep-learning](05-deep-learning/)
- [ ] Перцептрон, backpropagation
- [ ] Оптимизаторы (SGD, Adam)
- [ ] Регуляризация в нейросетях (dropout, batch norm)
- [ ] PyTorch
- [ ] CNN
- [ ] RNN / LSTM
- [ ] Attention и Transformer

### 6. NLP и CV → [06-nlp-cv](06-nlp-cv/)
- [ ] Эмбеддинги, токенизация
- [ ] Классификация текста
- [ ] Работа с изображениями, transfer learning

### 7. LLM и AI-агенты → [07-llm-agents](07-llm-agents/)
- [ ] Как работают LLM: токены, контекстное окно, параметры генерации (temperature, top-p)
- [ ] Работа с LLM через API: формат запросов, потоковый вывод, лимиты
- [ ] Prompt engineering: инструкции, few-shot, структурированный вывод (JSON)
- [ ] Эмбеддинги и векторные базы данных
- [ ] RAG (Retrieval-Augmented Generation): chunking, поиск, reranking, сборка контекста
- [ ] Tool use / function calling и AI-агенты: планирование, цикл «рассуждение → действие»
- [ ] Фреймворки для LLM: LangChain, LlamaIndex
- [ ] Оценка LLM-систем: метрики качества RAG, отладка промптов и пайплайнов

### 8. Подготовка к собеседованиям → [08-interview](08-interview/)
- [ ] Теоретические вопросы по ML
- [ ] Задачи по Python и SQL
- [ ] Алгоритмы и структуры данных (базовый уровень)
- [ ] Разбор ML-кейсов

## Практика

- [ ] Первый проект: end-to-end на табличных данных
- [ ] Второй проект: нейросети (NLP или CV)
- [ ] Третий проект: RAG-ассистент или AI-агент с API на FastAPI и тестами
- [ ] Участие в соревновании на Kaggle или хакатоне
- [ ] Оформить репозитории и резюме

## Теги

Теги пишутся в шапке главы: `tags: [theory, practice]`. Без `#`, слова через дефис.

**Тип содержимого**
- `theory`: идеи, математика, объяснения
- `practice`: код, эксперименты, ноутбуки
- `interview`: вопросы и задачи для собеседований

**Сквозные темы** (добавляются по мере необходимости)
- `optimization`, `metrics`, `regularization`, `probability`, `evaluation`
